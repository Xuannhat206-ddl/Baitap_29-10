BÀI 54 - HOTEL MANAGEMENT SYSTEM

1. Mở SQL Server Object Explorer (hoặc SSMS) -> New Query trên server -> mở file SQL\HotelDB.sql -> Execute.
2. Mở Bai54.sln bằng Visual Studio 2019/2022 (cần .NET Framework 4.8 targeting pack).
3. Mở Bai54\Form1.cs, sửa chuỗi connectionString (dòng đầu lớp Form1) cho đúng tên server của bạn.
4. Nhấn F5.
